## OSINT prompt

Generate one premium wide 16:9 photographic course cover asset for an OSINT professional training website. Scene: dark intelligence research workstation, large world map with delicate white connections on the background monitors, a physical dark globe and focused research desk foreground, a distant anonymous analyst viewed from behind in shadow on the right. Monochromatic black charcoal cold silver, restrained steel blue undertone. Cinematic realistic lighting, controlled contrast, credible enterprise cybersecurity visual, carefully composed, detailed but uncluttered. Similar to a high-end dark cybersecurity course hero. NO words, NO logos, NO numbers, NO neon, NO glowing borders, NO skulls, NO fantasy UI. Keep upper-left and left third darker for surrounding website headings; all text will be rendered in HTML. Image-only asset, not a website screenshot.

## Pentesting prompt

Create a wide 16:9 photographic editorial cover for a premium Web and API Pentesting training program. A dark professional security testing lab, anonymous analyst in a dark hoodie seated on the right viewed from behind, restrained monitors showing abstract web architecture and API request/response diagrams with subtle white lines, no legible text; realistic keyboard and equipment, cinematic realistic black charcoal and cold silver lighting, slight steel-blue undertone matching a monochrome OSINT intelligence-workstation cover. Composition fills frame with authentic work environment and deep shadows, clean high-end professional cybersecurity photography. No lettering, no logos, no neon, no skulls, no glowing UI, no fantasy effects, no watermark. Image asset only, not a website mockup.

## Usage

The latest user request explicitly asked for imagery like the supplied references, superseding the earlier PDF restriction on decorative images. Both images were inspected and used in the card and hero layouts. No text, fees or course facts are baked into the images; that information remains editable in Django admin.
