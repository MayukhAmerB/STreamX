# Course imagery policy

The course platform deliberately defaults to information-led cards and course headers. This follows the V2 requirements: no decorative cybersecurity scenes, fake terminal screens, neon/glow treatments or hooded-hacker imagery.

Course thumbnails are optional and controlled in Django admin. An existing thumbnail is preserved in storage and the database, but it is displayed only when the administrator enables **Show course image** for that course. Use that option only for imagery that directly explains the course, such as an instructor-led workshop, a real learning environment, a tool demonstration or a curriculum artefact.

Course names, summaries, facts, schedules, curriculum, benefits and prices are always rendered from editable database fields. No business information should be baked into an image.
